# Attribution and provenance

- **Layout.** The page layout follows the information architecture of the open-source [al-folio](https://github.com/alshedivat/al-folio) theme (MIT) and the publication-card style of [Sichen Tao's academic homepage](https://sichentao.github.io/academic-homepage/). All HTML, CSS and JavaScript in this repository were written independently. No code or text was copied from either project.
- **Paper figures.** The three publication thumbnails in `scripts/assets/img/pubs/` are Fig. 1 of the respective papers, all co-authored by Ruihan Zhao.
  - The image files come from Sichen Tao's homepage repository (`assets/img/publication_preview/`, commit 8a21c84) and were resized. That folder's `SOURCES.md` lists the publisher sources.
  - They are shown only to identify the papers. Copyright stays with the respective rights holders.
- **Fonts.** Self-hosted from the [Fontsource](https://fontsource.org/) packages:
  - Roboto: SIL Open Font License 1.1.
  - Roboto Slab: Apache License 2.0.

  Chinese text uses the visitor's system fonts.
- **ORCID iD icon.** Taken from orcid.org and used, as ORCID's brand guidelines allow, to link to the author's ORCID record.
- **JSON Resume schema.** Downloaded at build time from [jsonresume/resume-schema](https://github.com/jsonresume/resume-schema) (MIT) and used for validation only.
- **Bibliographic metadata.** From Crossref and arXiv. Citation counts are from OpenAlex, matched by DOI. Patent details were checked against Google Patents.
- **Journal metrics.** Adopted from the verification records in Sichen Tao's homepage (checked 2026-08-31). Each value is labelled with its year.
- **Content.** The site content, including the profile photo, is provided by Ruihan Zhao (赵瑞涵).
